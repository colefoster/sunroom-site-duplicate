# Sunroom visual world
Warm technical domesticity: cream paper, charcoal graphite, rich terracotta and honey tint. Big geometric lowercase wordmark; high-contrast short headlines. An interactive miniature desktop is the main visual, not decorative photography. Thin ruled sections and a generous unboxed layout. Product truth controls all prose. No eyewear imagery. Native app untouched. Mode: Persuade. The web demo explicitly models the native app; it does not control the user's display. Local fonts and assets, no dependencies.

Both the hero and playground show bright shared content, with the playground surrounded by a dark desktop. The hero toolbar opens native-style settings; its popover must remain above following sections. All overlay controls use the same per-instance behavior.
