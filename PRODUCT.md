# Sunroom
Marketing identity for the existing Sunglasses macOS application. Native app name remains Sunglasses. Confirmed from SunglassesApp.swift: menu-bar-only accessory app; translucent tinted region, click-through except Move & Resize mode; RGB picker; opacity 5–80%; Amber/Blue/Gray presets (30/25/35%); always-on-top setting; all Spaces; geometry and settings saved locally. macOS 13 minimum. No distributed binary verified, so install action supplies Xcode source-build instructions. No health claims, price, testimonials or unverified performance claims. User explicitly delegates all website design/name choices to Astra. Responsive product marketing page, working web demonstration.

Primary motivation: the user runs dark mode everywhere, but cannot control the light-mode screen someone else shares during a call. Lead with shading the shared window while keeping the rest of the Mac unchanged. Every tint illustration is a working, independent web demo with color, opacity, on/off, pinning, move/resize and locally remembered settings.
